---
headline: Quil now tells you what changed after an upgrade
---
- **Quil now shows what changed after an upgrade.** Launching a new version opens a
  short summary of the releases you skipped — features and changes in full, fixes
  collapsed to a count you can expand with `→`. It is also available at any time from
  `F1` → What's New.

  The summary is built from a one-line headline that each pull request now writes
  alongside its changelog entry, so it stays in the register you can read in half a
  minute rather than repeating the full entry.
